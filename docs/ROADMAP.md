# Roadmap For Paid Custom Work

## Starter package

- Configure one receiving wallet.
- Deploy the monitor and dashboard.
- Add a webhook receiver for Telegram, Discord, or an internal API.

## Growth package

- Invoice records with expected amount and due date.
- Matching logic for exact amount, sender allowlist, or memo/order id.
- SQLite/Postgres storage and CSV export.
- Admin login and audit trail.

## Multi-chain package

- USDT/USDC support on Base, Arbitrum, Polygon, Ethereum, Solana, or TRON.
- Unified payment event schema.
- Retry queue for webhooks.
- SLA monitoring and alerts.
